# Vendre ma voiture — AutoRA

Publiez votre annonce sur AutoRA, la marketplace automobile dédiée au marché belge.

## Comment vendre sur AutoRA

1. **Créez votre compte** sur https://autora.be/auth
2. **Cliquez sur "Vendre ma voiture"** dans le menu principal
3. **Remplissez le formulaire** : marque, modèle, année, kilométrage, carburant, prix, description
4. **Ajoutez des photos** de haute qualité (minimum recommandé : 5 photos)
5. **Publiez** — votre annonce est visible immédiatement après modération

## Informations requises

- Marque, modèle, version, année
- Kilométrage exact
- Type de carburant et boîte de vitesse
- Norme Euro (calculée automatiquement)
- Prix demandé
- Localisation (commune belge)
- Numéro Car-Pass (recommandé)
- Photos du véhicule

## Car-Pass obligatoire

En Belgique, le Car-Pass est obligatoire pour toute vente de voiture d'occasion entre particuliers. Obtenez le vôtre sur https://www.car-pass.be.
